¿Cómo funciona?

  1. 1
    Crea tu quiniela Ponle un nombre y pulsa "Crear". Se generará un código único (ej. NFL-4X8K2).
  2. 2
    Invita a tus amigos Comparte el código con el botón de compartir. Ellos entran a Quiniela → "Unirme" e ingresan el código.
  3. 3
    Haz tus pronósticos Cada semana elige quién crees que gana cada partido. Se guarda solo; una vez que empieza el partido, queda bloqueado.
  4. 4
    Compite por el primer lugar Ganas 1 punto por acierto. Mira la tabla de "Posiciones" para ver quién va ganando, toda la temporada hasta el Super Bowl.
